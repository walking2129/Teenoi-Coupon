เลือกสร้างได้ทีละแบบ: QR Code หรือบาร์โค้ด Code 128 ใส่รหัสแล้วสร้างเฉพาะรูปแบบที่เลือก จากนั้นลากย้ายและปรับขนาดได้

เลือกภาพแม่แบบเพื่อเริ่มต้น
ระบบจะนำข้อความนี้ไปสร้างตามรูปแบบที่เลือก และพิมพ์รหัสกำกับใต้ภาพให้อัตโนมัติ บาร์โค้ด Code 128 รองรับภาษาอังกฤษ ตัวเลข และสัญลักษณ์ทั่วไป ไม่รองรับภาษาไทย
