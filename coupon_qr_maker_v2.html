เครื่องมือสร้าง QR บนแม่แบบ

เลือกสร้างได้ทีละแบบ: QR Code หรือบาร์โค้ด Code 128 ใส่รหัสแล้วสร้างเฉพาะรูปแบบที่เลือก จากนั้นลากย้ายและปรับขนาดได้

เลือกภาพแม่แบบเพื่อเริ่มต้น
QR Code รองรับภาษาไทยและอีโมจิ โดยเข้ารหัส UTF-8 และวางบนแม่แบบโดยไม่เติมกรอบขาวขนาดใหญ่ (ยังคงระยะว่าง 4 โมดูลสำหรับสแกน) ส่วนบาร์โค้ด Code 128 รองรับภาษาอังกฤษ ตัวเลข และสัญลักษณ์ทั่วไป ไม่รองรับภาษาไทย ข้อความใต้โค้ดปรับขนาดแยกได้
